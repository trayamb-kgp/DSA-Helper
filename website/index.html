DSA Helper

A keystroke from stuck to unstuck.

A Chrome extension for LeetCode, Codeforces, CodeChef and GeeksforGeeks. It turns the problem you're looking at — and the code you've written — into a YouTube search or a ready-to-send ChatGPT review, without retyping a thing.

Coming soon to the Chrome Web Store

Three actions

From a shortcut, the toolbar popup, or the right-click menu.

Search YouTube Alt+Shift+Y

Opens YouTube results for a query built from the problem — e.g. LeetCode 912 Sort an Array solution.

Ask ChatGPT Alt+Shift+G

Opens ChatGPT with a full prompt already typed in — the problem, examples, constraints and your code. You read it and press Enter yourself.

Copy prompt

Puts that same prompt on your clipboard without opening anything.

Supported sites

Practice and contest pages, where each platform has them.

  • LeetCode · practice + contest
  • Codeforces · contest + gym
  • CodeChef · practice + contest
  • GeeksforGeeks · practice

Built the way you'd want it

  • The prompt and the search are templates you own — editable, with variables like {title}, {statement}, {constraints} and {code}, and a reset-to-default button.
  • Nothing is sent for you by default. The ChatGPT prompt is typed in and left for you to read; nothing reaches OpenAI until you press Enter.
  • Your code is the most protected thing it touches — never written to disk, never synced, never kept after the action that used it.
  • It degrades instead of breaking. If a site redesigns, you get a shorter prompt or a simpler search, and it tells you what it couldn't read.

Privacy, in one line
